# 沉默成本体检：离线示例与读法

> 「沉默成本体检」是本项目最反直觉的功能：**名义 ¥33.10 的临期券，只有 ¥13.10 排得上用**。
> 本文用 `silent_cost.py demo` 的离线输出，逐段解释「临期券 / 纸面富贵 / 排不上」三个概念。
> 数据为内嵌示例，**真实使用需 MCP Token**；本文不含真实订单、手机号、地址或 Token。

## 逐段解读

### 【一】临期券：7 天内到期、面值合计多少

报告先把「快要过期的券」单独列出来。本例三张临期券合计面值 **¥33.10**，
最急的「满50减12」只剩 1 天。

**怎么判断**：看「还剩几天」——7 天内到期、且面值合计超过一顿饭钱的，优先排掉；
过期即沉没，凑单达标也比浪费划算。

### 【一·B】用券排程：三个核心概念

排程把「过期窗口 × 你的点单频率」放在一起算：窗口 1 天、频率约 1 单，
意味着这轮只能消化 1 张券。于是三张券有了不同命运：

- **可实现（净价值）**：排得上的券才有价值。「9.9元中杯冰美式」净价值 **¥13.10**——
  这是唯一能在过期前真正用掉的一张。
- **纸面富贵**：门槛远超客单价，建议放弃。「满50减12」面值 ¥12.00，但客单价只有 ¥36.12，
  差 ¥13.88 才够门槛，净价值 **¥0.00**——名义上是钱，实际上用不掉。
- **排不上**：窗口内能点的单数少于临期券数，注定过期。「免费脆薯饼」还剩 2 天，
  这轮排不上，**¥8.00 沉没**。

汇总一行是全文最重要的一句：

> 名义 ¥33.10 → 可实现（净价值）¥13.10，注定过期 ¥20.00。

**怎么判断**：用「净价值 ÷ 名义面值」衡量券包质量。本例约 **39%**——
名义上的三张券，六成是纸面富贵或排不上。「券越多越省钱」之所以错，
是因为券的价值 = 面值 × 用得上概率，而囤券不花钱，只会制造「我有优惠」的错觉，
诱使你点掉本来不吃的凑单品。

### 【二】消费画像：排程的频率从哪里来

客单价 ¥36.12、近 4 单、高频单品麦辣鸡腿堡 ×4。排程按这个频率推算「1 单/天」，
所以「满50减12」才排不上——**画像直接决定排程结论**，改点什么、多久点一次，结论就变。

### 【三】积分体检：会过期的另一本账

300 积分本月过期（过期即清零），优先级高于券；积分影子价格 0.0210 元/积分，
可用积分折现 ≈ ¥25.20——用它判断「这单要不要动积分」的机会成本。

## 结论：这份报告怎么用

1. **每周跑一次**，先把 7 天内到期的券排进出菜单；排不上的趁早放弃或改需求，别为它凑单。
2. **纸面富贵的券要承认亏损**：门槛远超客单价的券，净价值为 0，继续持有只会误导决策。
3. **积分和券是两本账**：积分按月过期、可折现比较，优先兑换临期前会用到的餐品券。
4. 本示例数据来自本地 fixtures；接入真实账户需要 MCP Token。工具只做决策辅助——
   不自动领券、不自动下单，所有写操作都需你明确确认。

---

**English summary**: This example runs the silent-cost checkup fully offline. It shows how
near-expiry coupons are valued by *schedulable net value* rather than face value: ¥33.10 of
coupons yields only ¥13.10 of realizable savings, while ¥20.00 is doomed to expire. The same
logic applies to points, which expire monthly and carry a shadow price. Run it weekly, spend
what can be scheduled, and write off the rest honestly.
