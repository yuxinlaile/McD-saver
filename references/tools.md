> 依据 M-China/mcd-mcp-server 集成指南整理，并于 2026-10-10 通过
> `python scripts/mcd.py tools` 实测校准（服务器实际提供 35 个工具，

## 1. 营养健康

| 工具 | 说明 | 使用要点 |
|---|---|---|
| `list-nutrition-foods` | 餐品营养信息列表 | 能量、蛋白质、脂肪、碳水、钠、钙等。用户问"热量""营养"或要搭配指定热量套餐时使用 |

## 2. 地址与门店

| 工具 | 说明 | 使用要点 |
|---|---|---|
| `delivery-query-addresses` | 获取用户可配送地址列表 | 外送点餐第一步；为空则引导 `delivery-create-address` |
| `delivery-create-address` | 新增配送地址 | 用户无地址或需新增时使用 |
| `delivery-query-stores` | 查询可配送门店列表 | 基于收货地址返回附近可配送门店 |
| `query-nearby-stores` | 查询附近可用门店 | 到店场景；输入用户提供的地址 |
| `query-meal-assistance` | 查询助餐服务 | **仅企业团餐场景**，查询门店支持的助餐服务 |

## 3. 菜单与价格

| 工具 | 说明 | 使用要点 |
|---|---|---|
| `query-meals` | 查询当前可售卖餐品列表 | 返回分类、餐品编码、标签；点餐选品的入口 |
| `query-meal-detail` | 查询餐品详情 | 按餐品编码查询套餐组成与**可替换选项**（v1.0.5 起支持更换套餐内商品组合、部分餐品特制） |
| `calculate-price` | 商品价格计算 | 按商品列表（可含优惠券）计算商品金额、配送费、优惠金额及应付总价。支持到店(orderType=1)与外送(orderType=2)场景 |
| `query-promotions` | 查询团餐促销规则 | **仅企业团餐场景(beType=6)**，查询当前门店可用的满减/满折促销规则，用于搭配方案时估算优惠 |

## 4. 点餐与订单

| 工具 | 说明 | 使用要点 |
|---|---|---|
| `create-order` | 创建订单 | 按门店信息、就餐方式、商品列表创建订单，返回订单详情与**支付链接**。支持堂食/外带/外送/得来速/团餐，支持预约、餐具选择、订单备注（v1.0.9）、随单购买麦金卡和早餐卡（v1.0.6）、取餐柜二维码（堂食外带） |
| `cancel-order` | 取消订单 | 用户明确表达取消时使用；先 `query-order` 核对状态 |
| `query-order` | 查询订单详情 | 订单状态、内容、配送信息；查进度或确认信息 |
| `order-list` | 查询历史订单 | **近期的到店/外送订单**；商城订单请用 `mall-order-list` |
| `query-survey-coupon` | 查询订单满意度答卷 | 按订单号查询本人订单的 CSAT 满意度答卷，及关联奖券的标题、核销时间与状态 |

## 8. 主题活动（派对/品鉴会等）

以下五个工具构成严格的级联查询链，必须按序执行：

| 工具 | 说明 | 使用要点 |
|---|---|---|
| `query-party-city` | 可参与城市列表 | 级联第 1 步：先确定城市 |
| `query-party-store` | 指定城市下可参与门店列表 | 级联第 2 步：需要 storeCode |
| `query-partystore-date` | 指定门店下可预约日期 | 级联第 3 步：需要门店编码 |
| `query-partystore-session` | 指定门店、日期下可预约场次 | 级联第 4 步：需要日期 |
| `party-order-create` | 创建主题活动订单 | **写操作，需确认**（级联第 5 步） |

## 工具调用通用约定

1. **查询类工具**（query/list 开头）可自由调用，无副作用。
2. **写操作工具**在 SKILL.md"调用规范"约束下执行：先查后改、下单必确认。
3. 同一流程中，后续工具通常依赖前序工具返回的编码（storeCode、餐品编码、
   couponId、orderId 等），必须透传原始编码，不要转写或猜测。
4. 商城订单与点餐订单是两套体系：`order-list` ≠ `mall-order-list`，
   `query-order` ≠ `mall-order-detail`。
