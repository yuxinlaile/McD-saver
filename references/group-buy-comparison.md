# 外部团购比价方法论（美团 / 抖音等）

> 本文档说明"麦麦省钱助手"如何结合市面团购平台的优惠信息进行全渠道比价。
> 所有团购数据通过**用户手动录入**进入本地券库，比价结果为估算值。

## 一、为什么采用"手动录入"设计

美团、抖音等平台**未提供面向第三方的公开团购 API**，其价格与库存数据受
平台协议保护，无法（也不应）由本技能直接抓取。因此本技能采用诚实、合规的设计：

```
用户在美团/抖音 App 查询麦当劳团购券（代金券/套餐券）
        │  复制：标题、售价、面值、限制条件、有效期
        ▼
deal_compare.py add（录入本地券库 ~/.maimai_saver/deals.json）
        │
        ▼
deal_compare.py compare（与官方渠道 MCP 计算价格比价，输出推荐）
```

`scripts/deal_compare.py` 的数据层是插件化的：

- **本地券库**（默认）：`~/.maimai_saver/deals.json`，通过 `add` 子命令录入；
- **外部数据源 provider（显式可选）**：用命令行参数 `--provider <模块路径>`
  指向一个 Python 模块文件（需实现 `load_deals() -> list[dict]`，返回与券库
  JSON 相同结构的列表），即可在不改动决策逻辑的情况下接入自动化数据源；
  provider 加载失败时自动回退本地券库。若美团/抖音等平台未来开放官方 API，
  只需实现对应 provider，无需修改任何其他代码。

> ⚠️ **信任边界**：provider 模块的代码会在本机被执行（与 `pip install` 运行安装脚本同级风险）。
> 因此它只接受**命令行显式指定**的路径，不读环境变量——避免环境残留导致外部代码被静默执行；
> 执行前工具必定打印一行风险提示。旧版的环境变量 `MAIMAI_DEALS_PROVIDER` 已不再生效，
> 若检测到它被设置，工具会打印一次迁移提示。

## 二、录入字段与获取方式

| 字段 | CLI 参数 | 在团购页哪里看 |
|---|---|---|
| 平台 | `--platform` | meituan / douyin / eleme / other |
| 标题 | `--title` | 券名称，如"麦当劳满40减14代金券" |
| 售价 | `--price` | 券的购买价 |
| 面值 | `--face` | **可抵扣/覆盖的商品合计原价**（套餐券=套餐内商品原价合计；代金券=满减门槛金额） |
| 渠道 | `--channel` | 仅堂食(store) / 仅外送(delivery) / 通用(both) |
| 时段 | `--time` | 全时段(any) / 限时段(limited)，如"仅可用 10:30-14:00、17:00-20:00" |
| 有效期 | `--valid-until` | 券详情页"有效期至" |
| 限购 | `--quantity-limit` | "每桌限用1张"等 |
| 备注 | `--notes` | 其他限制（指定门店、节假日不可用等） |

## 三、比价折算口径

```
券折扣率       = 券售价 ÷ 券面值
同内容估算到手 = 官方渠道商品合计原价 × 券折扣率
节省金额估算   = 官方带券实付 − 同内容估算到手
```

**前提假设（必须人工核对）**：该券的适用范围能覆盖本次购买内容。
若订单内容超出券的适用范围，估算不成立。

## 四、比价五原则

1. **同店同品口径**：比较前确认团购券与官方订单覆盖**相同的门店范围与商品内容**，
   套餐内容不同的"低价"没有可比性。
2. **限制条件折算**：限时段、限堂食、限新客、节假日不可用等限制会显著降低券的
   实际价值，须完整录入并在报告中展示。
3. **叠加规则**：团购券通常**不可叠加**麦当劳官方优惠券与积分抵扣；
   团购价与"官方原价−官方券−积分"口径对比时要注意这一差异。
4. **有效期与沉没成本**：临期券（7 天内）会主动标记 [即将过期]；
   已过期券仅存档展示，不参与推荐。
5. **核销方式**：团购券多为到店出示核销，与外送场景天然不兼容；
   `--channel` 字段用于过滤不适用场景。

## 五、决策规则

| 情形 | 推荐 |
|---|---|
| 最优团购估算到手价 **低于** 官方带券实付 0.5 元以上 | 团购券（提示不可叠加官方券、需核对适用范围） |
| 官方带券实付 **不劣于或接近** 最优团购估算 | 官方渠道（可叠加会员权益/积分，退改灵活） |
| 券库为空或无有效券 | 官方渠道当前方案 |

## 六、合规与免责

- 本技能**不与任何团购平台对接、不抓取、不缓存其实时数据**；
  录入数据由用户提供，报告仅基于本地数据估算。
- 比价报告的每一项输出均标注"估算"，实际价格、库存与规则以
  美团/抖音/麦当劳官方页面实时信息为准。
- 比价的目的是帮助用户**以最优价格购买麦当劳产品**（全渠道购买决策辅助），
  不构成对任何平台或麦当劳官方渠道定价的评价。
