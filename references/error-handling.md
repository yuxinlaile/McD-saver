# 错误处理与排查指南

## 一、错误分类与处理矩阵

| 层级 | 错误类型 | 典型原因 | CLI 退出码 | 处理策略 |
|---|---|---|---|---|
| 鉴权 | `AuthError` (HTTP 401) | Token 无效、过期、未提供 | 2 | **不重试**。引导用户到 <https://open.mcd.cn/mcp> 控制台重新申请 Token，并更新 `MCD_MCP_TOKEN` 环境变量 / `~/.mcd_mcp_token` 文件 / `--token` 参数 |
| 限流 | `RateLimitError` (HTTP 429) | 超过 600 次/分钟/Token | 3 | CLI 已内置**指数退避 + 随机抖动**自动重试（尊重 `Retry-After` 响应头：指数部分上限 30s，服务器指示最长等 300s）。重试仍失败则告知用户稍后再试，并检查是否存在循环高频调用 |
| 传输 | `TransportError` | 网络不通、DNS 失败、超时、5xx | 4 | CLI 对 5xx 与网络错误自动重试（最多 `--retries` 次，默认 3）。仍失败则提示检查网络或服务器状态 |
| 工具 | `McpToolError` | 入参错误、业务规则不满足（如门店不营业、券不可用） | 1 | 读取错误详情 → 用 `schema <tool>` 重新核对参数 → 修正后重试（**最多 2 次**）；仍失败则将原始错误信息转述给用户，请其补充信息或调整需求 |

## 二、重试策略说明（mcd_client.py 内置）

```
第 n 次重试前等待 = min( 2^n + random(0,1) , 30s )      # 指数退避 + 抖动
若 429 响应携带 Retry-After 头 → 取 max(Retry-After, 上述值)
整体上限 = 300s                                          # 服务器要求更久时按 300s 截断
```

设计意图：
- **指数退避**：避免固定间隔在限流窗口内反复撞墙。
- **随机抖动**：多客户端并发时错峰重试。
- **Retry-After 优先**：尊重服务器明确的恢复时间指示（超过指数退避的 30s 上限也照等，最多 300s）。
- **重试也占配额**：每次实际发出的请求（含重试）都计入主动限速的滑动窗口。
- **401 不重试**：确定性错误，重试只会浪费配额。

## 三、Token 管理规范

| 项目 | 规范 |
|---|---|
| 存储 | 环境变量 `MCD_MCP_TOKEN`（推荐 CI/脚本）或文件 `~/.mcd_mcp_token`（推荐本地长期使用，权限建议 600） |
| 禁止 | 写入仓库文件、提交到 Git、出现在对话/日志/异常消息中 |
| 轮换 | 控制台重新申请后，删除旧文件内容并写入新 Token 即可，无需改代码 |
| 校验 | `python scripts/mcd.py check` 一步验证 Token 与连通性 |

## 四、常见问题排查

1. **`tools` 列表为空**
   - 检查 Token 是否有效（`check` 子命令）。
   - 确认 MCP Server 地址未被 `--url` / `MCD_MCP_URL` 改错。
2. **工具参数报错（McpToolError）**
   - 不要猜参数名：`python scripts/mcd.py schema <tool>` 查看权威 Schema。
   - 注意编码类参数（storeCode、餐品编码等）必须来自前序查询工具的返回值，原样透传。
3. **频繁 429**
   - 检查是否存在对 `query-meal-detail` 之类工具的循环逐个调用，改为按需查询。
   - Token 为每分钟 600 次上限，多端共用同一 Token 会共享配额。
4. **SSE 响应解析失败（TransportError: 无法解析的响应体）**
   - 服务器可能临时返回非标准内容；CLI 会自动重试一次网络路径。
   - 持续出现请提 Issue 并附 Content-Type（勿附 Token）。
5. **创建订单后用户未支付**
   - `query-order` 查看订单状态；未支付订单由用户决定继续支付或 `cancel-order`。

## 五、上报 Issue 的信息清单

- CLI 命令与参数（**隐去 Token**）
- 退出码与完整错误消息
- `python scripts/mcd.py check` 的输出（**隐去 Token**）
- 时间点（便于对齐服务器限流窗口）
