## 安装

1. 解压 `mcd-saver-v2.0.3.zip`，进入 `McD-Saver-v2.0.3/` 目录（仅需 Python 3.9+，无第三方运行依赖）。
2. 配置 MCP Token：`export MCD_MCP_TOKEN=<你的 Token>`（Windows PowerShell 用 `$env:MCD_MCP_TOKEN="..."`）。
3. 自检连通性：`python scripts/mcd.py check`；查看工具目录：`python scripts/mcd.py tools`。
4. 作为 Agent Skill 使用：把目录放到客户端的 skills 路径（详见 `references/agent-skill-installation.md`）。

> Token 申请：<https://open.mcd.cn/mcp>。本项目为社区开源作品，与麦当劳中国官方无隶属关系。

## 版本变更

### 新功能

- **官方最优方案自动衔接团购终局建议**（feasibility 早期提案落地）：
  `optimizer plan` / `demo` 输出后，若本地券库（MAIMAI_DEALS_FILE 或
  默认路径）非空，自动以「无券直点=原价口径、最优实付=官方基准」调用
  deal_compare 同口径折算，输出「官方最优 vs 团购最优」结论与适用限制——
  用户无需再手动跑两个工具；`--no-deals` 可关闭
  - 新增 `cross_channel_section()` 与 5 项测试（团购更低/官方更优/
    空券库/无券库/零基线）
  - 团购比价为全赛道独有功能（已验证 10 个竞品均未实现）
