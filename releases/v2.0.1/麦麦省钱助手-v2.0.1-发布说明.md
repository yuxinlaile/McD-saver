## 安装

1. 解压 `mcd-saver-v2.0.1.zip`，进入 `McD-Saver-v2.0.1/` 目录（仅需 Python 3.9+，无第三方运行依赖）。
2. 配置 MCP Token：`export MCD_MCP_TOKEN=<你的 Token>`（Windows PowerShell 用 `$env:MCD_MCP_TOKEN="..."`）。
3. 自检连通性：`python scripts/mcd.py check`；查看工具目录：`python scripts/mcd.py tools`。
4. 作为 Agent Skill 使用：把目录放到客户端的 skills 路径（详见 `references/agent-skill-installation.md`）。

> Token 申请：<https://open.mcd.cn/mcp>。本项目为社区开源作品，与麦当劳中国官方无隶属关系。

## 版本变更

### 新功能

- **在线试算页移动端导入路径**（客户以手机使用为主，手机无终端无法执行命令）：
  - 移动端显示专属引导——两条无需电脑的导入路径：已安装 AI Agent 的
    「说一句导入真实菜单 → 复制输出 → 粘贴回页」；以及
    **menu.json 文件选择导入**（新增文件按钮，FileReader 本地读取）
  - 桌面命令生成流程保留（窄屏自动隐藏，桌面自动显示），互不干扰
- 该功能经 375px 移动视口与 1366px 桌面视口双端实测：文件导入成功、
  无横向溢出、团购列表渲染正常
