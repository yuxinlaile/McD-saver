## 安装

1. 解压 `mcd-saver-v1.7.0.zip`，进入 `McD-Saver-v1.7.0/` 目录（仅需 Python 3.9+，无第三方运行依赖）。
2. 配置 MCP Token：`export MCD_MCP_TOKEN=<你的 Token>`（Windows PowerShell 用 `$env:MCD_MCP_TOKEN="..."`）。
3. 自检连通性：`python scripts/mcd.py check`；查看工具目录：`python scripts/mcd.py tools`。
4. 作为 Agent Skill 使用：把目录放到客户端的 skills 路径（详见 `references/agent-skill-installation.md`）。

> Token 申请：<https://open.mcd.cn/mcp>。本项目为社区开源作品，与麦当劳中国官方无隶属关系。

## 版本变更

### 新功能

- **点餐替换建议**：当最优方案仍超出热量或钠上限时，按「热量代价从小到大」
  逐项给出替换选项（如 中可乐 → 无糖可乐），表达喜爱的单品最后才动，
  每处替换说明营养变化
- **口味记忆**：去酸黄瓜、可乐去冰等个人偏好只需说明一次，会话内自动
  记忆并写入后续点餐的特调参数

### 改进

- 点餐工作流（SKILL.md）与上述两项行为对齐，Agent 在营养约束触发时
  主动给出替换路线而非仅提示超限
- 在线试算页文案表述规范化

### 文档

- 新增 **MCP 实战踩坑指南**（`references/mcp-pitfalls.md`）：响应格式、
  金额单位、券字段多态、菜单时效性等 8 条实测经验，帮助接入者少走弯路
- README 新增**「能力现状」**披露：已验证 / 待真实环境复核 / 已知限制，
  一张表说明项目成熟度
- README 明确**订单安全边界**：用户确认前不创建订单，创建订单不等于支付成功
- 全仓库文案与目录整理：开发过程记录归档至 `docs/`，移除未使用的示意图资源
