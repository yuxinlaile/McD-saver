## 安装

1. 解压 `mcd-saver-v1.7.4.zip`，进入 `McD-Saver-v1.7.4/` 目录（仅需 Python 3.9+，无第三方运行依赖）。
2. 配置 MCP Token：`export MCD_MCP_TOKEN=<你的 Token>`（Windows PowerShell 用 `$env:MCD_MCP_TOKEN="..."`）。
3. 自检连通性：`python scripts/mcd.py check`；查看工具目录：`python scripts/mcd.py tools`。
4. 作为 Agent Skill 使用：把目录放到客户端的 skills 路径（详见 `references/agent-skill-installation.md`）。

> Token 申请：<https://open.mcd.cn/mcp>。本项目为社区开源作品，与麦当劳中国官方无隶属关系。

## 版本变更

### 改进

- **在线试算页移动端优化**（客户以手机使用为主）：
  - 触控：按钮最小高度 44px，移动端卡片间距压缩（18px → 14px）
  - 表单：输入类字号统一 16px，规避 iOS Safari 聚焦时的页面强制缩放
  - 布局：Token 卡两输入框窄屏纵向堆叠，消除 375px 宽度下的横向滚动；
    优化结果卡在移动端置顶（order:-1），选完餐品即见结果
  - 视觉：新增 theme-color，移动浏览器地址栏与页面配色一致
- 桌面端布局与字号不受影响（全部改动限定在 ≤640px 媒体查询内，回归验证通过）
