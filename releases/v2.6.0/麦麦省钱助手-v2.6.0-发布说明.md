## 安装

1. 解压 `mcd-saver-v2.6.0.zip`，进入 `McD-Saver-v2.6.0/` 目录（仅需 Python 3.9+，无第三方运行依赖）。
2. 配置 MCP Token：`export MCD_MCP_TOKEN=<你的 Token>`（Windows PowerShell 用 `$env:MCD_MCP_TOKEN="..."`）。
3. 自检连通性：`python scripts/mcd.py check`；查看工具目录：`python scripts/mcd.py tools`。
4. 作为 Agent Skill 使用：把目录放到客户端的 skills 路径（详见 `references/agent-skill-installation.md`）。

> Token 申请：<https://open.mcd.cn/mcp>。本项目为社区开源作品，与麦当劳中国官方无隶属关系。

## 版本变更

**多单用券排程 `--timeline`**：把券排到未来每一次点单，输出到日期粒度的时间轴。

### 新增

- **多单用券排程 `--timeline`**：按到期日把券排到未来每一次点单，逐单给出「第几单 / 日期 / 用哪张券 / 净价值」，
  并汇总可实现金额与到期浪费；`--horizon N` 指定观察期（默认到最晚到期日，上限 60 天）。
  `report` 与 `demo` 子命令均支持，报告新增【一·C】区块。
- **`analyze_coupon_book`**：保留全部可识别有效期的券。此前 `analyze_coupons` 只保留 7 天内临期券，
  有效期更长的券被整体丢弃，长券在短窗口里会被误判「排不上」。
- **分配规则**：净价值降序，每张券排到不晚于其到期日的最后一个空位（带截止期的单位时间调度最优解），
  随后前移压缩以提升可读性。演示数据下，「先到期先用」可实现 ¥13.00，最优分配为 ¥18.10。
- 观察期内预计不足 1 单时，报告标注「按历史频率只排今天这一单」，不假设用户会下单。

### 变更

- 券净价值计算抽为 `_coupon_net_value`，单窗口排程与多单时间轴共用同一口径。
- README 中英、SKILL.md 补充 `--timeline` 说明与命令示例。

### 质量

- 337 项测试全过（新增 8 项：全量券册、最优分配、过期浪费、纸面富贵、观察期上限、频率缺失、报告区块等）
- 覆盖率 80%（515 / 2513 语句）
- 已用真实 MCP 响应验证：4 张券（剩余 0/0/2/4 天）在观察期 4 天内排程，输出与手工核算一致
