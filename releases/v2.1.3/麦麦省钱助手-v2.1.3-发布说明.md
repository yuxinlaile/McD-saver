## 安装

1. 解压 `mcd-saver-v2.1.3.zip`，进入 `McD-Saver-v2.1.3/` 目录（仅需 Python 3.9+，无第三方运行依赖）。
2. 配置 MCP Token：`export MCD_MCP_TOKEN=<你的 Token>`（Windows PowerShell 用 `$env:MCD_MCP_TOKEN="..."`）。
3. 自检连通性：`python scripts/mcd.py check`；查看工具目录：`python scripts/mcd.py tools`。
4. 作为 Agent Skill 使用：把目录放到客户端的 skills 路径（详见 `references/agent-skill-installation.md`）。

> Token 申请：<https://open.mcd.cn/mcp>。本项目为社区开源作品，与麦当劳中国官方无隶属关系。

## 版本变更

### 改进

- **在线试算页四维约束支持直接输入数值**：预算 / 热量 / 蛋白质 / 钠四条滑杆
  旁新增数值输入框，与滑杆双向联动——可键入精确值（支持小数、也可超出滑杆
  原量程），留空或 0 表示不限，非法输入标红且不生效，失焦自动归一化；
  约束变更后若已有计算结果会即时重算，无需再点计算按钮
- **移动端数值框触控优化**：输入框高度 40px、滑杆占满整行，单手操作更稳
- **修复窄屏卡片右侧被裁切**：菜单网格轨道改用 `minmax(0, 1fr)`，375px 视口下
  卡片宽度回归容器宽度（实测 343px、内部零溢出），桌面双列布局不受影响
