## 安装

1. 解压 `mcd-saver-v1.7.2.zip`，进入 `McD-Saver-v1.7.2/` 目录（仅需 Python 3.9+，无第三方运行依赖）。
2. 配置 MCP Token：`export MCD_MCP_TOKEN=<你的 Token>`（Windows PowerShell 用 `$env:MCD_MCP_TOKEN="..."`）。
3. 自检连通性：`python scripts/mcd.py check`；查看工具目录：`python scripts/mcd.py tools`。
4. 作为 Agent Skill 使用：把目录放到客户端的 skills 路径（详见 `references/agent-skill-installation.md`）。

> Token 申请：<https://open.mcd.cn/mcp>。本项目为社区开源作品，与麦当劳中国官方无隶属关系。

## 版本变更

### 改进

- **用券排程升级为净价值模型**（净价值 = 券面价值 − max(0, 满减门槛 −
  自然消费基准)，模型借鉴 [mcd-coupon-strategist](https://github.com/Ayzzz123/mcd-coupon-strategist)
  的 planner.py，MIT License）：门槛远超客单价的满减券判定为
  「纸面富贵」并建议放弃，不再计入可实现金额——修正了此前
  按面值排程导致的系统性高估
- 排程建议展示从「面值」改为「净价值」，超出客单价的门槛部分如实说明

### 修复

- **客单价口径修正**：0 元订单（券核销/积分兑换）此前被计入客单价分母，
  会系统性拉低「自然消费基准」——现改为消费口径（客单价剔除 0 元单）
  与点单口径（频率含全部订单）分离，并新增 `free_order_count` 字段
  与报告披露（口径分离思路借鉴同上项目 auditor.py）
