## 安装

1. 解压 `mcd-saver-v2.1.0.zip`，进入 `McD-Saver-v2.1.0/` 目录（仅需 Python 3.9+，无第三方运行依赖）。
2. 配置 MCP Token：`export MCD_MCP_TOKEN=<你的 Token>`（Windows PowerShell 用 `$env:MCD_MCP_TOKEN="..."`）。
3. 自检连通性：`python scripts/mcd.py check`；查看工具目录：`python scripts/mcd.py tools`。
4. 作为 Agent Skill 使用：把目录放到客户端的 skills 路径（详见 `references/agent-skill-installation.md`）。

> Token 申请：<https://open.mcd.cn/mcp>。本项目为社区开源作品，与麦当劳中国官方无隶属关系。

## 版本变更

### 新功能

- **主动滑动窗口限速**（`scripts/mcd_client.py`）：
  默认 300 次/分钟（官方上限 600 的一半），批量比对场景不再触发 429 被动等待；
  `rate_limit=0` 可禁用。新增 4 项测试（禁用/窗口满等待/窗口未满/滑出）
- **方案排名场景标签**（经济 / 均衡 / 丰盛）：
  Top-N 方案自动标注「最经济 / 均衡 / 最丰盛」，排名可读性提升

### 文档

- README 新增 **dependencies stdlib-only 徽章** 与搜索关键词区
- Pages 根路径新增索引页（原根路径 404，现自动进入在线试算）
