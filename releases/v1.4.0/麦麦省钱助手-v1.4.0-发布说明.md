## 安装

1. 解压 `mcd-saver-v1.4.0.zip`，进入 `McD-Saver-v1.4.0/` 目录（仅需 Python 3.9+，无第三方运行依赖）。
2. 配置 MCP Token：`export MCD_MCP_TOKEN=<你的 Token>`（Windows PowerShell 用 `$env:MCD_MCP_TOKEN="..."`）。
3. 自检连通性：`python scripts/mcd.py check`；查看工具目录：`python scripts/mcd.py tools`。
4. 作为 Agent Skill 使用：把目录放到客户端的 skills 路径（详见 `references/agent-skill-installation.md`）。

> Token 申请：<https://open.mcd.cn/mcp>。本项目为社区开源作品，与麦当劳中国官方无隶属关系。

## 版本变更

### Added
- optimizer.py：**多约束支持**——`--budget` 实付预算上限与 `--max-kcal` 热量上限
  （菜单含 kcal 字段时生效），违反约束的方案排后并标注"超预算/超热量 xx"，
  不静默删除；**套餐替换枚举**——套餐含 `contains` 字段覆盖全部想吃单品时
  自动生成"改点套餐"候选，是否更省交给计价排名判断
- silent_cost.py：**积分影子价格**——`--mall` 传入积分商城商品列表后，
  按 max(面值÷积分) 估算最优兑换效率并给出可用积分折现值
  （统一成本口径）
- 单元测试 75 → 84（新增约束/套餐替换/影子价格用例）

### Changed
- SKILL.md 工作流 5 补充约束参数说明；README 中英运行与命令同步
