## 安装

1. 解压 `mcd-saver-v2.3.0.zip`，进入 `McD-Saver-v2.3.0/` 目录（仅需 Python 3.9+，无第三方运行依赖）。
2. 配置 MCP Token：`export MCD_MCP_TOKEN=<你的 Token>`（Windows PowerShell 用 `$env:MCD_MCP_TOKEN="..."`）。
3. 自检连通性：`python scripts/mcd.py check`；查看工具目录：`python scripts/mcd.py tools`。
4. 作为 Agent Skill 使用：把目录放到客户端的 skills 路径（详见 `references/agent-skill-installation.md`）。

> Token 申请：<https://open.mcd.cn/mcp>。本项目为社区开源作品，与麦当劳中国官方无隶属关系。

## 版本变更

品牌统一：把仍然残留在身份字段里的旧名（`maimai-saver` / `maimai_saver` / `MAIMAI_*`）
全部改为 `McD Saver` 体系，并说明 Star History 图表滞后的原因。

### 改进

- **品牌统一（旧名 `maimai-saver` → `mcd-saver`）**：仓库、Release、在线试算页早已改名为
  `McD-saver`，但包名、技能名、客户端 UA、安装路径、数据目录、券库环境变量仍沿用旧名，
  造成「对外一个新名、对内一个旧名」的双重口径。现统一为：
  - 包名 `mcd-saver`（`pyproject.toml`）、技能名 `mcd-saver`（`SKILL.md` frontmatter）、
    客户端标识 `mcd-saver/<version>`（`mcd_client.CLIENT_INFO` / `USER_AGENT`）；
  - 安装路径示例统一为 `~/.claude/skills/mcd-saver`、`~/.workbuddy/skills/mcd-saver` 等
    （`references/agent-skill-installation.md` 共 20 处）；
  - 数据目录 `~/.mcd_saver`，券库环境变量 `MCD_DEALS_FILE` / `MCD_DATA_DIR`；
  - 试算页导出的分享图文件名 `mcd-savings-card.png`；报告页脚 `McD Saver (mcd-saver)`。
- **兼容性保障**：旧环境变量 `MAIMAI_DEALS_FILE` / `MAIMAI_DATA_DIR` 仍然生效（优先级低于新名），
  既有用户配置不会失效；`MAIMAI_DEALS_PROVIDER` 的迁移提示保持不变。
- **Star History 说明**：该图表由 star-history.com 服务端定期抓取并缓存，数据会滞后数小时到一天；
  README 顶部新增 **shields.io 实时 Stars 徽章**（每次读取都是真值），并在图表下方注明滞后原因，
  避免读者把旧曲线当成当前星数。
- 新增 `tests/test_brand_rename.py`（7 项）：锁定身份字段用新名、新旧环境变量优先级、
  并扫描全仓确保旧名不再出现在身份字段中（历史记录除外）。
