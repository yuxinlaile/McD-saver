## 安装

1. 解压 `mcd-saver-v2.1.2.zip`，进入 `McD-Saver-v2.1.2/` 目录（仅需 Python 3.9+，无第三方运行依赖）。
2. 配置 MCP Token：`export MCD_MCP_TOKEN=<你的 Token>`（Windows PowerShell 用 `$env:MCD_MCP_TOKEN="..."`）。
3. 自检连通性：`python scripts/mcd.py check`；查看工具目录：`python scripts/mcd.py tools`。
4. 作为 Agent Skill 使用：把目录放到客户端的 skills 路径（详见 `references/agent-skill-installation.md`）。

> Token 申请：<https://open.mcd.cn/mcp>。本项目为社区开源作品，与麦当劳中国官方无隶属关系。

## 版本变更

### 新功能

- **在线试算页四维约束滑杆**：预算 / 热量上限 / 蛋白质下限 / 钠上限四条滑杆，
  31 项示例菜单全部补充营养数据（示例值，真实数据以官方 nutrition 接口为准）；
  违规方案排后并标注差多少（与 CLI 同一语义，绝不静默剔除）
- **真实运行验证记录**：新增 `scripts/verify_run.py` 一键生成脱敏验证记录写入
  `examples/verified-run.md`——真实 Token 环境实测：35 工具连通、完整调用链跑通，
  Token 与手机号自动排除

### 改进

- **CI 覆盖率门槛**：pytest-cov 接入，`--cov-fail-under=55`（当前 64%）
- **Token 文件权限检查**：Unix 上 `~/.mcd_mcp_token` 权限过宽时提示 chmod 600
- **代码拆分**：HTML 渲染与省钱等级抽离为 `silent_report.py`（silent_cost 保持
  向后兼容再导出）
- 版本工具补 pyproject.toml 同步（此前为覆盖盲区）

### 修复
