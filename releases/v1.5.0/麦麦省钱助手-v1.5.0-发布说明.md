## 安装

1. 解压 `mcd-saver-v1.5.0.zip`，进入 `McD-Saver-v1.5.0/` 目录（仅需 Python 3.9+，无第三方运行依赖）。
2. 配置 MCP Token：`export MCD_MCP_TOKEN=<你的 Token>`（Windows PowerShell 用 `$env:MCD_MCP_TOKEN="..."`）。
3. 自检连通性：`python scripts/mcd.py check`；查看工具目录：`python scripts/mcd.py tools`。
4. 作为 Agent Skill 使用：把目录放到客户端的 skills 路径（详见 `references/agent-skill-installation.md`）。

> Token 申请：<https://open.mcd.cn/mcp>。本项目为社区开源作品，与麦当劳中国官方无隶属关系。

## 版本变更

### Added
- optimizer.py：**营养约束**——`--min-protein`（蛋白质下限，g）与
  `--max-sodium`（钠上限，mg），配合菜单条目的 `protein`/`sodium` 字段
  （来自 list-nutrition-foods）生效；违规方案排后并如实标注
  「蛋白质不足 xx g / 超钠 xx mg」；**营养数据缺失的方案按不满足处理**
  并标注「蛋白质未知」——延续"算不出如实披露"原则，绝不虚构达标。
  健身增肌与控盐人群场景（借鉴 mcd-order-calories 的营养口径思路）
- demo.html 页脚增加 GitHub Star 引导链接
- 单元测试 89 → 98（新增营养约束用例：达标不打标 / 不足排后 /
  数据缺失保守处理 / 组合约束排序 / 报告文案）
