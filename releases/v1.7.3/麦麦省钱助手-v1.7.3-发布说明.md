## 安装

1. 解压 `mcd-saver-v1.7.3.zip`，进入 `McD-Saver-v1.7.3/` 目录（仅需 Python 3.9+，无第三方运行依赖）。
2. 配置 MCP Token：`export MCD_MCP_TOKEN=<你的 Token>`（Windows PowerShell 用 `$env:MCD_MCP_TOKEN="..."`）。
3. 自检连通性：`python scripts/mcd.py check`；查看工具目录：`python scripts/mcd.py tools`。
4. 作为 Agent Skill 使用：把目录放到客户端的 skills 路径（详见 `references/agent-skill-installation.md`）。

> Token 申请：<https://open.mcd.cn/mcp>。本项目为社区开源作品，与麦当劳中国官方无隶属关系。

## 版本变更

### 新功能

- **在线试算页「🔑 导入你的真实菜单」卡片置顶**：输入 MCP Token 一键生成
  现成命令（Windows / macOS-Linux 双版本，内嵌 `--token`，无需预设环境变量），
  复制到本地终端执行后把输出粘贴回页面，即可用实时全量菜单跑同一套优化算法。
  Token 仅在浏览器内存中拼接命令，不上传任何服务器（浏览器直连 MCP 受
  CORS 限制，此为实测后最安全便捷的路径）
- **团购示例扩充 6 → 11 条**：新增板烧鸡腿堡中套餐券、早餐组合两件套券、
  抖音巨无霸中套餐单次券、满 30 减 8 代金券、双层吉士中套餐单次券，
  覆盖套餐单次券 / 满减代金券 / 双人餐 / 随心配 / 甜品 / 早餐六类
