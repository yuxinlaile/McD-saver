## 安装

1. 解压 `mcd-saver-v2.0.0.zip`，进入 `McD-Saver-v2.0.0/` 目录（仅需 Python 3.9+，无第三方运行依赖）。
2. 配置 MCP Token：`export MCD_MCP_TOKEN=<你的 Token>`（Windows PowerShell 用 `$env:MCD_MCP_TOKEN="..."`）。
3. 自检连通性：`python scripts/mcd.py check`；查看工具目录：`python scripts/mcd.py tools`。
4. 作为 Agent Skill 使用：把目录放到客户端的 skills 路径（详见 `references/agent-skill-installation.md`）。

> Token 申请：<https://open.mcd.cn/mcp>。本项目为社区开源作品，与麦当劳中国官方无隶属关系。

## 版本变更

### 新功能

- **版本号自动递增工具**（`scripts/version.py`）：实现本项目自定义
  z.x.y 版本格式与递增规则——修订号 y 上限 3、次版本号 x 上限 6，
  每次发布先递增 y，y 超限进位到 x 并重置，x 超限进位到 z 并将 x、y
  重置（示例：1.5.3 → 1.6.0，1.6.3 → 2.0.0，历史过渡版本 1.7.4 → 2.0.0）
  - CLI：自动读取仓库当前版本（单一事实源 CLIENT_INFO）输出下一版本；
    `--apply` 一键写回发布四件套（CLIENT_INFO / SKILL.md / README×2 徽章）
  - 边界处理：0.0.0 起步递增、超限分量归一化进位、非法输入
    （非数字/段数错误/负数/空串）抛出明确错误
  - 单元测试 32 项：规则表、进位链、边界与非法输入全覆盖
- **版本格式切换说明**：自本版本起采用 z.x.y 自定义格式，
  v1.7.4 之后进入 2.0.0
