## 安装

1. 解压 `mcd-saver-v1.4.1.zip`，进入 `McD-Saver-v1.4.1/` 目录（仅需 Python 3.9+，无第三方运行依赖）。
2. 配置 MCP Token：`export MCD_MCP_TOKEN=<你的 Token>`（Windows PowerShell 用 `$env:MCD_MCP_TOKEN="..."`）。
3. 自检连通性：`python scripts/mcd.py check`；查看工具目录：`python scripts/mcd.py tools`。
4. 作为 Agent Skill 使用：把目录放到客户端的 skills 路径（详见 `references/agent-skill-installation.md`）。

> Token 申请：<https://open.mcd.cn/mcp>。本项目为社区开源作品，与麦当劳中国官方无隶属关系。

## 版本变更

### Added
- `mcd.py` 新增 `claim` 子命令：列出麦麦省可领券（available-coupons）→
  展示清单 → 交互确认（y/N，`--yes` 供脚本场景）→ auto-bind-coupons 一键领取。
  安全边界：用户主动触发、单次执行；**明确不提供定时轮询与无人值守后台**
  （此类自动化有 Token 风控封禁风险，与 SKILL.md「下单必确认」规范一致）
- 单元测试 84 → 89（claim 流程用例：直接领取/确认领取/取消/空清单/大小写）
