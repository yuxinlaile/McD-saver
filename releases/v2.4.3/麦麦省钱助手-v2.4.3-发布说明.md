## 安装

1. 解压 `mcd-saver-v2.4.3.zip`，进入 `McD-Saver-v2.4.3/` 目录（仅需 Python 3.9+，无第三方运行依赖）。
2. 配置 MCP Token：`export MCD_MCP_TOKEN=<你的 Token>`（Windows PowerShell 用 `$env:MCD_MCP_TOKEN="..."`）。
3. 自检连通性：`python scripts/mcd.py check`；查看工具目录：`python scripts/mcd.py tools`。
4. 作为 Agent Skill 使用：把目录放到客户端的 skills 路径（详见 `references/agent-skill-installation.md`）。

> Token 申请：<https://open.mcd.cn/mcp>。本项目为社区开源作品，与麦当劳中国官方无隶属关系。

## 版本变更

修复非中文 Windows 下中文输出崩溃，补齐券相关的排错条目。

### 修复

- **非中文 Windows 下中文输出崩溃**：控制台编码为 cp1252 时，`python demo.py` 与各 CLI 打印中文抛
  `UnicodeEncodeError`，命令整体失败。新增 `scripts/console.py`，各入口在 `main()` 开头把非 UTF-8 的
  stdout/stderr 切到 UTF-8（`errors="replace"` 兜底），已是 UTF-8 的流不动；
  新增 `tests/test_console.py`（5 项，含「所有入口统一兜底」守卫）。

### 文档

- `references/error-handling.md` 的「常见问题排查」补 3 条券相关条目：券不在本店/本渠道可用、
  未达使用门槛、不在可用时段或已过期，均按「症状 → 原因 → 怎么办」组织。
